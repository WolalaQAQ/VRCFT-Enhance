VRCFT-Enhance @VERSION@
Target host: VRCFaceTracking @HOST_VERSION@
Upstream commit: @UPSTREAM_COMMIT@

This package contains a matched VRCFaceTracking.Core.dll and
VRCFaceTracking.ModuleProcess.dll. Check provenance.json and the target
above before installing. Do not use the 5.4.5 package with VRCFT 6 or mix
Core and ModuleProcess from different packages.

Installation
1. Close VRCFaceTracking.
2. Copy the entire matching, unmodified VRCFaceTracking installation to a
   separate directory. Keep the original Steam installation unchanged.
3. Replace the two DLLs in the COPY with this package's two DLLs.
4. Run VRCFaceTracking.exe from the copy.

The copy shares %APPDATA%\VRCFaceTracking modules and settings with the
official host. Do not run both at the same time. Return to the original
host by launching it from Steam. After a Steam update, make a fresh copy
and use a patch explicitly targeting that update; do not copy a previous
patched directory over the updated installation.

Options (positive integer milliseconds; read once at startup)
  --osc-poll-ms=4       VRCFT_OSC_POLL_MS
  --osc-output-ms=4     VRCFT_OSC_OUTPUT_MS
Command-line options override process environment variables.

Defaults are 4 ms. Poll controls module snapshot requests. In VRCFT 5,
output controls the periodic sender wait. In VRCFT 6, sending remains
reply-driven and output controls the maximum wait for other modules to
reply. It is NOT a fixed OSC output interval in VRCFT 6.

Native face blobs require VRCFT 6 and a compatible Avatar. The patch does
not add native output to VRCFT 5. The left outer brow belongs to the eye
module; an expression-only setup without an eye module loses that brow.

安装
1. 关闭 VRCFaceTracking。
2. 把完整、未修改且版本匹配的 VRCFaceTracking 安装目录复制到新目录，

3. 用包内两个 DLL 替换副本中的同名文件。
4. 从副本运行 VRCFaceTracking.exe。

从 Steam 启动即可回到原版。Steam 升级后应重新复制正式目录，并使用明确匹配
该版本的补丁；不要把旧补丁目录直接覆盖到新版安装上。

设置（正整数毫秒，只在启动时读取）
  --osc-poll-ms=4       VRCFT_OSC_POLL_MS
  --osc-output-ms=4     VRCFT_OSC_OUTPUT_MS
命令行优先于进程环境变量。默认均为 4 ms。

poll 控制模块快照请求间隔。VRCFT 5 的 output 控制定时发送等待；
VRCFT 6 保留收到回复触发发送，output 只控制等待其他模块回复的最长合并窗口，
不是固定的 OSC 发送周期。

原生整脸 blob 需要 VRCFT 6 与兼容 Avatar；补丁不会给 VRCFT 5 增加原生输出。
左外眉归眼部模块；只用表情模块、不用眼部模块时，该眉不再由表情模块更新。
